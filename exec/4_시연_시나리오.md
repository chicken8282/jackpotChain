# 4. 시연 시나리오

> 시연 순서에 따른 site 화면별, 실행별(클릭 위치 등) 상세 설명

---

## 시연 흐름 개요

```
학습 페이지 → 채굴 페이지 → 지갑 페이지 → 로또 페이지 → 대시보드
```

---

## 4.1 학습 페이지

### Step 1: 로드맵 확인
1. 상단 네비게이션에서 **[학습]** 클릭
2. 학습 랜딩 페이지에서 **전체 로드맵**(0~5단계, 13개 모듈) 표시
3. 각 단계의 완료 상태와 진행률 바를 보여줌
4. **"블록체인을 6단계로 배워봅시다"** 등 개요 설명

### Step 2: 학습 파트 상세 (개념 학습 → 체험 → 검증)
1. 로드맵에서 **[1단계: 신뢰]** > **[1.1 투명한 유리 금고]** 클릭
2. **개념 학습 탭**:
   - 상단 메인 일러스트(유리 큐브 애니메이션) 확인
   - 하단 3개 카드 (**투명성 / 분산 저장 / 조작 불가**) 순서대로 클릭
   - 각 카드 모달에서 애니메이션 + 설명 텍스트 확인 → 닫기
3. **챗봇 활용**:
   - 우하단 **[싸또에게 물어보기]** FAB 버튼 클릭
   - "블록체인이 뭐야?" 등 질문 입력 → AI 응답 확인
4. **체험하기 탭** 클릭:
   - 분산 원장 체험: 텍스트 입력 → **[기록 추가]** 클릭
   - 4개 노드에 동시 기록되는 모습 확인
5. **검증 미션 탭** 클릭:
   - 3개 퀴즈를 순서대로 풀기
   - 정답/오답 피드백 확인

### Step 3: 리포트 보기
1. 모든 모듈 학습 완료 후 **[리포트 보기]** 버튼 클릭
2. 학습 완료 인증서 및 스킬 레이더 차트 확인
3. 네트워크 전파 및 동기화 흐름 최종 설명

---

## 4.2 채굴 페이지

### Step 1: TUI 다운로드 및 설명
1. 상단 네비게이션에서 **[채굴]** 클릭
2. 채굴 페이지에서 **TUI 다운로드 방법** 안내 섹션 확인
3. Windows/Mac/Linux별 설치 방법 설명

### Step 2: 채굴 TUI 실행
1. **터미널에서 TUI 실행**:
   ```bash
   python -m blockchain.tui
   ```
2. **지갑 생성**: TUI 내 지갑 메뉴에서 새 지갑 생성
3. **노드 참여**: 네트워크에 연결, Status 화면에서 블록 높이/피어 수 확인
4. **채굴 시작**: Mining 탭에서 채굴 시작 → 블록 생성 실시간 확인
5. **로또 참여**: TUI 내 Lotto 메뉴에서 번호 선택 → 참여

---

## 4.3 지갑 페이지

### Step 1: 기존 지갑 등록
1. 상단 네비게이션에서 **[지갑]** 클릭
2. **[지갑 등록하기]** 버튼 클릭
3. TUI에서 생성한 지갑의 **개인키**를 입력
4. 비밀번호 설정 → 브라우저 IndexedDB에 암호화 저장
5. 인증 과정: 서버 챌린지 → 개인키로 서명 → 자동 로그인

### Step 2: 지갑 정보 확인
1. 등록된 지갑의 **잔액** (JACK / POT) 실시간 표시
2. **활동 기록** 탭: 송금, 수신, 채굴 보상, 교환 내역 스크롤
3. 각 활동의 트랜잭션 ID, 금액, 시간 표시

---

## 4.4 로또 페이지

### Step 1: 로또 참여
1. 상단 네비게이션에서 **[로또]** 클릭
2. **번호 선택** 영역에서 0x0~0xF 중 6개 번호 클릭 (또는 **[랜덤 생성]** 버튼)
3. 선택된 번호 확인 후 **[로또 참여하기]** 클릭
4. POT 차감 확인 (100 JACK = 1 POT)

### Step 2: 참여 내역 확인
1. 하단 **참여 내역** 목록에서:
   - 상태: `추첨 중` / `당첨` / `미당첨` / `만료`
   - 선택 번호 vs 결과 번호 비교
   - 당첨 시 보상 금액 표시
2. **당첨 순위** 탭에서 역대 당첨자 랭킹 확인

---

## 4.5 대시보드

### Step 1: 전체 화면 구성 설명
1. 상단 네비게이션에서 **[대시보드]** 클릭
2. 메인 영역:
   - **블록체인 시각화**: 최근 블록들이 체인 형태로 연결된 3D 시각화
   - **잭팟 풀**: 현재 잭팟 풀 잔액 실시간 표시
   - **네트워크 상태**: 노드 수, 동기화 상태

### Step 2: 블록 상세보기
1. 블록체인 시각화에서 **특정 블록 클릭**
2. 블록 상세 모달:
   - 블록 높이, 해시, 이전 블록 해시
   - 채굴자 주소, 난이도, 논스
   - 포함된 트랜잭션 목록

### Step 3: 블록 높이 및 노드 네트워크
1. **블록 높이** 위젯: 현재 체인의 최신 블록 높이
2. **노드 네트워크** 위젯: 연결된 피어 노드들의 네트워크 토폴로지 시각화
