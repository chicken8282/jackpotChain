# 2. 외부 서비스 정보

> 프로젝트에서 사용하는 외부 서비스를 정리한 문서

---

## 2.1 사용 외부 서비스 목록

| 서비스명 | 용도 | 가입/발급 필요 여부 |
|----------|------|---------------------|
| SSAFY GMS API | 지도/위치 기반 서비스 API | SSAFY 교육생 API 키 발급 필요 |
| DockerHub | Docker 이미지 저장소 (CI/CD에서 push/pull) | 계정 필요 |
| GitLab (lab.ssafy.com) | 소스코드 저장소 및 MR 관리 | SSAFY 계정 |
| AWS EC2 | 서버 호스팅 (Dev/Prod) | AWS 계정 + SSH 키 |
| Jenkins | CI/CD 파이프라인 자동화 | EC2 내 설치됨 |

---

## 2.2 SSAFY GMS API

- **용도**: 프론트엔드에서 지도/위치 관련 기능 사용
- **가입 방법**: SSAFY 교육 포털에서 GMS API 키 발급
- **적용 위치**: `FE-ssatto/.env.local`

```bash
VITE_GMS_API_KEY=<발급받은 API 키>
VITE_GMS_HOST=https://gms.ssafy.io/gmsapi
```

- **빌드 시 주입**: Jenkinsfile에서 `--build-arg VITE_GMS_API_KEY` 으로 Docker 빌드 시 주입
- **Jenkins 설정**: Credential ID `gms-api-key` (String 타입)로 등록

---

## 2.3 DockerHub

- **용도**: CI/CD 파이프라인에서 빌드한 Docker 이미지를 push하고, 배포 서버에서 pull
- **리포지토리**: `jooyoonjang/jackpotchain-be`, `jooyoonjang/jackpotchain-fe`, `jooyoonjang/jackpotchain-node`
- **태그 정책**: Jenkins `BUILD_NUMBER`를 이미지 태그로 사용
- **Jenkins 설정**: Credential ID `dockerhub-creds` (Username/Password 타입)

---

## 2.4 AWS EC2

- **용도**: Dev/Prod 서버 호스팅
- **서버 주소**: `15.165.75.53` (ubuntu 사용자)
- **접속 방법**: SSH 키 기반 (`main-ec2-ssh` Jenkins Credential)
- **필수 소프트웨어**: Docker, Docker Compose, Nginx, Git

### 서버 디렉토리 구조

```
~/deploy-repo/       # GitLab 소스 클론 (Jenkins가 관리)
~/app/
  ├── compose/       # docker-compose 파일들
  ├── scripts/       # 배포 스크립트들
  ├── env/           # .env.dev, .env.prod
  └── monitoring/    # Prometheus, Grafana, Loki 설정
```

---

## 2.5 Jenkins

- **용도**: GitLab push 이벤트를 감지하여 자동 빌드/배포
- **트리거 브랜치**:
  - `develop` → Dev 환경 배포
  - `master` / `main` → Prod 환경 배포 (Blue/Green)
- **필요 Credentials**:

| Credential ID | 타입 | 용도 |
|---------------|------|------|
| `dockerhub-creds` | Username/Password | DockerHub 로그인 |
| `gms-api-key` | Secret text | Frontend GMS API 키 |
| `main-ec2-ssh` | SSH Username with private key | EC2 SSH 접속 |

---

## 2.6 외부 서비스 없이 로컬 실행

본 프로젝트는 **Docker Compose 로컬 실행 시 외부 서비스 의존도가 최소화**되어 있습니다.

- PostgreSQL, Redis, RabbitMQ: 모두 Docker 컨테이너로 로컬 실행
- 블록체인 노드: Docker 컨테이너로 로컬 실행 (외부 피어 연결 없이 단독 채굴 가능)
- GMS API 키: 지도 기능을 사용하지 않으면 빈 값으로도 앱 기동 가능

```bash
# 외부 서비스 없이 전체 로컬 실행
docker compose -f docker-compose.local.yml --env-file .env.local up -d
```
