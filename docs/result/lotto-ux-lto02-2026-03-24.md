# LTO-02: 로또 UX 개선 3종

**날짜**: 2026-03-24

## Overview

로또 UX 불편 3가지를 FE-ssatto 레이어(`HexPicker.tsx`)에서 개선했다.

1. **LTO-02-A**: 커밋 성공 후 "참여 내역" 탭으로 즉시 전환 (기존: 2초 후 전환)
2. **LTO-02-B**: 수령 버튼 클릭 직후 버튼 즉시 숨김 (optimistic state)
3. **LTO-02-C**: 히스토리 리스트에서 "당첨" 배지 옆에 상금 금액 표시

### 변경 상세

**LTO-02-A** (`handleParticipate`):
- `setShowSuccessModal(true)` 직후 `setTab("history")` 추가 → 커밋 성공 즉시 히스토리 탭 전환
- SuccessModal은 fixed overlay이므로 탭 전환과 무관하게 2초간 표시됨
- 기존 `useEffect`에서 `setTab("history")` 제거 (모달 닫기만 담당)

**LTO-02-B** (`handleClaim` + state):
- `claimedEntryIds: Set<string>` 상태 추가
- `handleClaim()` 성공 후 `setClaimedEntryIds(prev => new Set([...prev, entryId]))` 호출
- 히스토리 리스트 "수령" 버튼 조건: `entry.claimable && !claimedEntryIds.has(entry.id) && onClaim`
- `LottoPage.handleClaim()`에서 `refetchLottoOverview()` 이미 호출 중 → 잔액 갱신은 기존 로직으로 처리됨

**LTO-02-C** (히스토리 리스트 렌더링):
- `statusLabel === "WINNING" && entry.rewardLabel` 조건 시 배지 옆에 금액 span 추가
