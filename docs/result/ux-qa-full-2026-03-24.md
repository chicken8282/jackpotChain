## Critical Issues (심각도 HIGH 이상)

### 1. [DASH-03] 미정의 라우트에서 빈 화면 렌더링

- **심각도**: High
- **재현 단계**: `http://localhost:13000/unknown-route` 접근
- **실제 동작**: App.tsx에 `*` catch-all Route가 없어서 Navbar + 빈 영역만 렌더링
- **예상 동작**: 404 안내 화면 표시 또는 `/`(대시보드)로 리디렉션
- **영향**: 잘못 입력한 경로에서 사용자가 이유 없이 빈 화면을 보게 됨
- **수정 방법**:
  ```tsx
  // App.tsx Routes 마지막에 추가
  <Route path="*" element={<Navigate to="/" replace />} />
  // 또는 별도 NotFound 컴포넌트
  ```

### 2. [AUTH-04/API] auth/refresh, auth/logout — body 누락 시 500 반환

- **심각도**: Medium (FE는 항상 body를 전송하므로 실 사용자 영향 없음)
- **재현 단계**:
  ```bash
  curl -X POST http://localhost:8080/v1/auth/refresh
  curl -X POST http://localhost:8080/v1/auth/logout
  ```
- **실제 동작**: `HttpMessageNotReadableException` → 500 "서버 내부 오류가 발생했습니다."
- **예상 동작**: 400 "잘못된 요청입니다." (또는 "요청 본문이 필요합니다.")
- **원인**: Spring 컨트롤러의 `@RequestBody` 파라미터에 대한 예외 처리 누락
- **영향**: 비표준 클라이언트, 공격자 프로빙 시 내부 오류 코드 노출. API 스펙상 불명확

### 3. [WALLET-LOCK-04] 세션 만료 모달 자동 오픈 — 수동 E2E 미검증

- **심각도**: High (코드 구현 완료, 검증 필요)
- **구현 상태**: 코드 변경 완료, TypeScript 타입 오류 없음, Docker 빌드 healthy
- **미검증 항목**: 실제 브라우저에서 컨테이너 재시작 → 지갑 페이지 → WalletUnlockModal 자동 오픈 여부
- **검증 방법**:
  ```bash
  docker compose --env-file .env.local -f docker-compose.local.yml restart backend
  # 브라우저에서 http://localhost:13000/wallet 새로고침
  # 예상: WalletUnlockModal이 "세션이 만료되었습니다." 문구와 함께 자동으로 열림
  ```
